# Isla Viva — Sitio multipágina con Bootstrap

Proyecto académico responsivo con páginas de inicio, portafolio, detalles y contacto. Utiliza Bootstrap 5, validación de formulario y una personalización visual en naranja, verde y blanco.


## Requisitos demostrados

- HTML semántico y CSS personalizado.
- Bootstrap integrado mediante CDN en las páginas.
- Barra de navegación, botones, tarjetas, formulario, alertas, badges y sistema Grid.
- Selectores de elemento (`body`, `section`, `footer`), clases (`.hero`, `.tarjeta-proyecto`) e ID (`#confirmacion`).
- Propiedades de color, tipografía, fondo, dimensiones, transición y sombra.
- Modelo de caja con `box-sizing`, `margin`, `padding`, `border` y `border-radius`.
- Diseño responsivo con `container`, `row`, `col-lg-*`, `row-cols-*` y `@media`.
- Validación de formulario con clases de Bootstrap y JavaScript.

## Laboratorio JavaScript

La página `laboratorio.html` demuestra y permite probar:

- Condicionales `if`, `else if` y `else` mediante un recomendador.
- Bucles `for`, `while` y `do...while`.
- Iteración de un arreglo de destinos turísticos.
- Funciones con parámetros, valores de retorno y tareas específicas.
- Alcance global, local y de bloque.
- Clausuras mediante un contador que conserva su estado privado.
- Pruebas automáticas con `console.assert()`, `console.table()` y `console.group()`.
